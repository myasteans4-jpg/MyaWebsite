Accessibily Considerations

I would incorporate accessibility on my website by making it usable for everyone to use. I would also incorporate accessibility on my website by using clear headings, color, navigation and images. I would add the correct order for titles and subtitles (h1, h2, h3) so people can easily read my page. I would add the right color for the text and background that stand out well so people can read them easily. I would make sure every button, link and menu works when I'm using only the keyboard's tab and arrow keys. I would add clear images of the hobbies I chose. Each image will introduce that hobby and explain about it. Everyone will get to learn, explore and use my website. This isn't just my website, it's for everyone to learn and enjoy.
